Политика конфиденциальности

Обновлено: 2026-10-09

Эта политика описывает обработку данных в Android-приложении MemeLab. Разработчик и контакт по вопросам данных — Pavlo Khomenko, hompavlik@gmail.com.

1. Какие данные обрабатываются

  • Аккаунт: email, имя, идентификатор Firebase, статус подтверждения почты и сведения для авторизации. Пароль обрабатывает Firebase Authentication; в нашей базе профилей пароль не хранится.
  • Генерации: выбранные фотографии, изображение-образец, описание, шаблон, результат, время и статус задания. Доступ к фотографиям предоставляется через системный выбор файлов.
  • Работа сервиса: идентификаторы заданий, лимиты, безопасные коды ошибок и технические журналы.
  • Analytics и Crashlytics: события использования, экраны, сведения о сбоях, версия приложения и ОС, модель устройства и идентификаторы установки. SDK также могут обрабатывать сетевые данные для доставки и защиты сервиса.

2. Для чего нужны данные

Для входа и восстановления доступа, создания выбранных изображений, хранения личной коллекции, исполнения запросов удаления, ограничения злоупотреблений и исправления ошибок. Статистика помогает понять, какие функции работают и где возникают проблемы.

Мы не добавляем имя, email, фото, текст запроса или UID аккаунта в события Analytics и пользовательские поля Crashlytics. Рекламный идентификатор и персонализация рекламы отключены. В этой версии нет рекламных SDK.

3. Обработка внешности

Фотографии лица используются для генерации образа по вашему запросу. Приложение не выполняет проверку личности и не создаёт собственную базу биометрических шаблонов для идентификации людей. Загружайте только свои фотографии или материалы людей, разрешивших такую обработку.

4. Кому передаются данные

Google Firebase обеспечивает авторизацию, базу, хранение файлов, серверную обработку, Analytics и Crashlytics. OpenAI API получает выбранные изображения и описание для генерации; мы не включаем ваш email или имя профиля в запрос генерации. Передача происходит при запуске этой функции. Эти сервисы могут обрабатывать данные за пределами вашей страны.

По условиям обработки данных OpenAI API содержимое API по умолчанию не используется для обучения моделей; журналы контроля злоупотреблений могут храниться до 30 дней, с предусмотренными провайдером исключениями. Удаление файлов из MemeLab не означает немедленного удаления служебных записей провайдера. Подробнее: конфиденциальность Firebase.

5. Хранение и удаление

Аккаунт, профиль и результаты хранятся до удаления соответствующего мема или аккаунта. Исходные фото и текст задания удаляются из рабочей очереди и хранилища MemeLab после обработки. Для оставшихся незавершённых загрузок предусмотрена периодическая очистка файлов старше 24 часов; при сбоях или большой очереди очистка может занять больше времени.

Технические журналы и данные SDK хранятся по настройкам и правилам соответствующего сервиса. Сводная статистика может сохраняться отдельно. Файлы, которые вы сохранили на устройство или отправили другим людям, не удаляются при удалении аккаунта.

6. Приватность коллекции

В приложении нет публичной ленты. Пользовательский доступ к коллекции ограничен вашим аккаунтом; разработчик и поставщики инфраструктуры обрабатывают данные для работы и поддержки сервиса. Отправка изображения через меню «Поделиться» передаёт его выбранному вами приложению или получателю.

7. Ваши запросы

Имя можно изменить в профиле. Данные и аккаунт можно удалить через приложение либо запросить удаление по email: порядок удаления. По этому же адресу можно запросить доступ, исправление или разъяснение обработки данных. Для защиты аккаунта может потребоваться подтверждение владения email. Не отправляйте нам пароль.

Если считаете, что данные ребёнка были предоставлены без необходимого разрешения, напишите разработчику для проверки и удаления.

8. Этот сайт и изменения

На сайте политики нет форм сбора данных, рекламных или аналитических скриптов и собственных cookies. Firebase Hosting может обрабатывать обычные сведения HTTP-запроса для обслуживания и защиты сайта. При изменении приложения мы обновляем эту страницу и дату выше.
